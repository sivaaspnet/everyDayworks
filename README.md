## 📝 Daily Log Format

Each day contains:

- Date
- Tasks Planned
- Tasks Completed
- Learning Topics
- Issues Faced
- Solutions
- Time Spent
- Tomorrow's Plan

Example:

```
Date: 30-Jul-2026

Completed
- User CRUD API
- SQL optimization
- React form validation

Learning
- Window Functions
- Git Rebase

Issues
- EF Core Tracking Error

Solution
- Used AsNoTracking()

Tomorrow
- Role Management API
```
